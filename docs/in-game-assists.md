# 局内辅助功能

设置入口：**设置 → 游戏玩法 → 局内辅助**。各项默认关闭，保存后按用户选择加载，不再由 `Settings.migrate()` 强制禁用。增强出兵不在本次恢复范围内；旧 `enableOffscreenPanel` 仍强制关闭。

## 功能行为

- 攻击范围：建筑独立开关；移动单位有「不显示 / 地面 / 空中 / 全部」四档。轮廓圈使用队伍颜色，海上单位归「全部」。额外按钮可切换建筑圈、循环单位范围模式，也可单独标记当前选中的单位。
- 单位目标线：沿用单人或本队单位的目标信息；敌方目标在迷雾不可见时不绘制。
- 改进血条：保留原版显示条件、位置、长度、边框与血量变化动画，HP 填充在 30%～60% 为橙色、低于 30% 为红色，60% 及以上沿用原版队伍颜色。护盾、能量、建造进度不改色。两端均生效。
- 快速选择：全 / 建 / 海 / 空 / 陆。只选本地玩家已建成、存活、未装载且原版允许选择的单位。「全」是全部作战单位，不含建筑与建造者；「建」包含建筑。悬浮和水陆两栖单位同时归海、陆；建造者不加入作战单位分类。观战及回放不显示此条。
- 时间与延迟：按引擎对局时间显示 `分钟:秒`，联网且有有效延迟时附加 `ms`。回放保留原版已有的时钟，不重复叠加。
- 放大按键：将保护、巡逻两个原版动作按钮从缩小比例恢复到完整比例，不改变动作、命令或网络包。

## 架构与线程

1. `rwpp-core-api/game/ui/InGameAssistRules.kt` 管理分类、颜色、时钟与 HUD 布局规则，无 Compose 依赖。
2. `rwpp-core/game/InGameAssistRenderer.kt` 缓存少量 Paint，在原版单位渲染回调中画轮廓圈和目标线。没有独立线程、整屏位图、离屏 Compose、GL 纹理上传或自定义 shader。
3. 两端 `UnitAssistInject` 对单位 `a(float, boolean)` 追加绘制。调用方先判断死亡、装载和原版迷雾可见性；相机变换交给引擎，不再手动重复缩放。血条仅重定向该方法中的 `a(RectF, Paint)`，复制 Paint 属性后改色，绝不修改引擎缓存的共享 Paint。
4. 两端 `InGameHudInject` 在原版菜单 HUD 回调中绘制快捷条，调用原版按钮函数登记命中区域，消费抬起事件，防止地图点穿。在该引擎回调中直接选择单位，不从 Compose / Android UI / Swing EDT 改选中列表，不排队到下一帧。
5. `GameUnit.attackRangeHighlighted` 是原版单位上注入的一个本地 Boolean 字段，不恢复旧逐单位组件列表，不写存档、不改变单位校验和、不发自定义联机包。随单位释放，无跨会话对象缓存。
6. 保连接模组重载期间两类注入均跳过。暂停菜单打开时快捷条与自定义时钟隐藏。HUD 根据当前可玩区域和引擎 UI 缩放布局，避开侧栏与底部编队；过小窗口隐藏，窗口和全屏切换无需重建覆盖层。
7. Android KSP 通过 `lib/android.jar` 解析血条重定向所需的 `RectF` / `Paint`，此文件只作编译期 classpath，不追加为注入或发布库。

## 验证

自动检查：

```powershell
.\gradlew.bat :rwpp-core-api:test
.\gradlew.bat :rwpp-core:testDebugUnitTest --tests BundleParseTest
.\gradlew.bat :rwpp-desktop:compileKotlin :rwpp-android:assembleDebug
.\gradlew.bat :rwpp-desktop:packageReleaseUberJarForCurrentOS
```

`InGameAssistRulesTest` 覆盖配置保存/迁移、分类边界、血量阈值、时钟和窄屏布局；`InGameAssistInjectionTest` 使用真实两端游戏 jar 验证绘制重定向与追加注入的组合、原逻辑保留、按钮大小注入及输入 accessor 的字节码。

设备验收清单：

1. 单人遭遇战和多人对局逐项启用，检查范围圈和目标线随平移/缩放同步，迷雾内不泄露敌方单位或目标。
2. 选择低血量单位，检查 HP 分段颜色；护盾、能量与建造进度保持原色。
3. 点击各快捷分类，检查装载单位、建造者、建筑和两栖单位归类；确认点击/拖动不会产生地图移动命令。
4. 切换范围额外按钮，选中圈可独立开关，单位模式有文字状态；关闭所有开关后退出再进设置，检查保存。
5. 对局中开设置、开聊天、暂停/继续、切后台/恢复、退出再开新局；桌面缩放窗口并切全屏，检查 UI 位置、输入和会话标志。

编译和字节码验证不能代替设备上的视觉、输入及帧率验收。尤其 Android 不同 ROM 的绘图后端和触摸行为需要真机检查。
