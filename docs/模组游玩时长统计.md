# 模组云端游玩时长

极速版 Android 与桌面端均通过独立的 Go `modplaytime` 服务上报。服务使用 MySQL，并在 `.env` 中配置数据库与统一账号认证服务；部署说明和完整查询接口见服务项目的 `README.md`。

## 客户端配置

在启动器「设置」中填写「模组时长统计服务器」，值是服务的基址，例如 `https://playtime.example.com`，不附加 `/api/v1`。留空关闭统计，也停止投递已排队记录；更换地址后不会再向旧服务器重发。默认留空，部署服务后才启用。

桌面开发也可通过环境变量或 JVM 系统属性覆盖，系统属性优先：

```powershell
$env:RWJS_MOD_PLAYTIME_API_URL = "http://127.0.0.1:11457"
```

```text
-Drwjs.modPlaytime.apiUrl=http://127.0.0.1:11457
```

Android 真机需要填写电脑或服务器可达的地址；`127.0.0.1` 指向手机自身。

## 统计口径

- 只记录已经登录统一账号后的本地游玩时间，登录前的数据不补记。切号、登出开始即停止旧身份计时并清除其未交付队列，旧对局不会借用新账号的 token 上报。
- 单人遭遇战、沙盒、任务、生存、多人对局和继续游戏均通过引擎的实际运行状态采样。菜单、战役室、加载、模组同步、暂停、后台冻结、回放、观战及败北后的观看不计时。
- 使用单调时钟累计现实秒数；游戏加速不放大时长。每秒采样，状态变化的边界间隔保守不计；长时间没有采样不补算。
- 每局冻结实际生效的单位模组、当前地图所属模组，以及已注册且可用的音乐模组。管理页勾选状态不作为单位模组已经加载的证据。
- 同时使用多个模组时，每个模组累计本局完整活跃时长，例如两款模组玩 30 分钟，各记 30 分钟。
- 每 30 秒上报累计值；退出、回菜单或断连时结算。已落盘的失败请求指数退避重试，同一账号原 token 恢复后可继续交付。服务端按 session 的累计差额入账，因此重发、乱序响应和重复结束不会重复统计。
- 上报队列最多保留 256 个 session。正常运行中落盘与网络请求独立；设置页与队列保存串行读取当前配置，桌面使用同目录临时文件原子替换，Android 使用原子 SharedPreferences 提交。异常退出仍可能丢失尚未落盘的尾段，哈希尚未完成的记录也无法恢复。

## 模组身份

服务端以模组名称与 64 位小写 SHA-256 联合区分模组版本。

`.rwmod` 和独立 `.ini` 使用原文件字节的流式 SHA-256。目录模组使用与现有模组同步一致的规范化 ZIP：递归按名称排序、路径分隔符为 `/`、条目时间为 0、压缩级别为 1，再流式计算 SHA-256。根目录名称、文件修改时间不会改变目录身份；房主目录打包后的网络模组与原目录得到同一哈希。已验证的网络缓存复用原名称和传输哈希，避免缓存文件名制造另一个模组身份。

哈希在 IO 线程每局计算一次，不在每次心跳重复扫描，也不分配整个模组的字节数组。不可读取的模组跳过统计并写日志。

## 接口

所有统计与查询请求携带统一账号 `Authorization: Bearer <token>`；身份由服务端验证，请求体不接受客户端自报用户 ID。

```http
POST /api/v1/playtime/reports
Content-Type: application/json
Authorization: Bearer <token>

{
  "session_id": "093a135b-d485-4cf8-9601-d6ff342c4ec4",
  "elapsed_seconds": 30,
  "mods": [{"name": "示例模组", "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"}],
  "ended": false
}
```

同一个 session 的模组集合固定，`elapsed_seconds` 只能增长，最长 604800 秒。退出时仍用同一 UUID，并设置 `ended: true`。响应为 `{session_id, elapsed_seconds, added_seconds, ended}`；客户端确认 session ID、累计秒数及结束标志后才移除对应的已交付请求。

```http
GET /api/v1/playtime?mod_name=示例模组&mod_sha256=<sha256>&user_id=7&limit=50&offset=0
GET /api/v1/playtime?account=alice&limit=50&offset=0
```

`mod_name`、`mod_sha256` 可按需组合。用户筛选可传 `user_id` 或账号 `account`；不传时查询当前认证用户。当前客户端提供自动上报和服务地址设置，统计展示由查询接口提供。

## 验证

```powershell
.\gradlew.bat :rwpp-core-api:test :rwpp-core:testDebugUnitTest
.\gradlew.bat :rwpp-desktop:compileKotlin :rwpp-android:compileDebugKotlin
```

自动测试覆盖传输身份一致性、暂停与休眠、累计请求、延迟确认、退出期间哈希、切号隔离、快速换局及恢复队列。平台采样还需要在真实客户端验证单人、多人与各平台的生命周期路径；编译通过不代表已完成真机对局验证。
