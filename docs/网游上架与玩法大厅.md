# 网游上架与玩法大厅

第二主界面「玩法大厅」从固定开放平台读取 `GET /api/v1/games`，专注展示平台已审核上架的新版网游玩法（原版多人、战役与生存入口保留在第一主界面，不再混入玩法大厅）。网游名称、介绍、封面、区服和美术包版本由平台已审核目录提供。旧平台没有该接口（404）时显示空态舞台与刷新入口；请求失败会提示重试，不生成演示网游。原来的「申请 24 小时列表位」不变。

进入大厅时立即拉取目录，可见期间每 30 秒刷新，隐藏时暂停。失效请求会清除网游条目并显示重试状态。区服离线时仍可进入已批准的网游网页查看公告，网页入口自身未配置或停用时卡片显示「入口维护中」。

登录后点击网游卡片，会打开供应商网页。玩家在网页选择区服，客户端重新获取官方资料并核对区服可用性及资源版本。首次下载可选美术包时，玩家可以改用默认外观。下载必需扩展包需要玩家确认，取消后仍可返回原网页。接口及浏览器权限见 [网游网页入口](网游网页入口.md)。

客户端只使用平台登记的实际 IP:port；目录客户端拒绝域名、短码、建房命令、换行和非法端口。不携带 UAS Token、开发者密钥或节点密钥获取目录，不跟随 HTTP 重定向，并限制响应大小。HTTPS 资源地址可使用查询参数；带用户名密码、fragment 或非环回明文 HTTP 的资源地址被拒绝。

网页入口与普通多人入口共用 `NativeRoomEntry`，调用 `GameSessionController` 和同步协调器执行原版入服。美术包在等待旧会话清理之后、预同步与连接之前临时应用。取消或失败只清理本轮请求，成功后关闭网页，离房恢复原美术包和大厅。玩家专属外观还需通过实际游戏 Socket 核验身份，核验失败时使用默认玩家外观。

下载资源存放在主题目录内独立的 `.online-game-packs/<pack_id>/<catalog_hash>/`，不覆盖同 ID 的用户美术包。归档最多 64MiB，解压最多 256MiB/4096项，单项最多 32MiB、清单及文字覆盖最多 1MiB；拒绝重定向、路径穿越和大小写重复。安装前校验归档 SHA-256，安装后核对包 ID、版本及实际个性化资源目录 SHA-256。没有下载地址时可以使用本地完全匹配的版本，否则仍可选择默认外观加入。临时切换不写入玩家保存的主题设置；同一代次重复激活、迟到取消和显式手动切包均不会覆盖玩家后来的选择。

已绑定过网游的包只在该网游作用域下下发专属分配；暂停、解绑或普通无网游查询不会使其变成通用分配。需要通用外观时另行登记独立包。客户端以实际 Socket 对端查询得到的 `game_app_id` 和绑定目录为准，不能把目录卡片、包内声明或自报昵称当作网游或槽位证明。
