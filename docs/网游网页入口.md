# 网游网页入口

玩法大厅中的网游卡片打开审核通过的供应商网页。未登录时先完成客户端账号登录；未配置或已停用网页入口时保留公开卡片并提示暂不可用。网页不再有原生区服选择页。普通多人联机、邀请、收藏和快速开房保持原入口。

## 客户端接入

官方目录的 `portal_url` 与 `portal_revision` 确定入口和权限版本。入口支持 HTTP 或 HTTPS，可填写公网 IP 与端口，并带查询参数及 `#` 路由。浏览器只给该入口的主文档、精确 scheme/host/port 提供桥接。iframe、跨来源导航及旧文档均不能调用。外部 HTTP 或 HTTPS 链接交系统浏览器，禁止网页要求客户端连接任意游戏地址。

页面收到 `rwGameReady` 事件后，可以使用客户端注入的 API：

```javascript
let joinSequence = 0;
const player = await rwGame.getPlayer(); // {accountId, nickname}
const identity = await rwGame.authorize({nonce: serverGeneratedNonce});
// {code, expires_at, game_app_id}，交供应商后台立即兑换，不要持久保存。
const servers = await rwGame.getServers();
// [{serverId, name, available, online, currentPlayers, maxPlayers, closedMessage}]
const requestId = `join-${++joinSequence}`;
rwGame.onJoinStateChanged(event => {
  // event: {requestId, serverId, state, message?}
  // state: preparing / joining / joined / failed / cancelled
});
await rwGame.joinServer({serverId: servers[0].serverId, requestId});
// 只表示客户端已受理；joined 才表示原生入服确认完成。
await rwGame.cancelJoin({requestId});
```

`nonce` 必须由供应商后台为当前网页登录尝试生成，使用 32–128 位 ASCII 字母、数字、下划线或减号。供应商后台需要把 nonce 与当前会话绑定，校验身份兑换结果所属游戏。网页获得的只是 60 秒有效、一次性身份码。UAS JWT、支付密码、开发者 Secret 和邮箱不会交给网页。

同一主文档内，业务 `requestId` 与 `serverId` 绑定。重试同一请求返回原有进度或终态，不会再次连接；同 ID 换区服会被拒绝。单文档最多受理 256 个不同请求 ID，容量用尽需重新打开页面。取消会等待原生连接、席位预约与内容恢复完成，期间新的加入请求被拒绝；完成后才返回 `cancelled`。
取消期间重放原 `joinServer` 请求可获得 `state: "cancelling"` 回执；它是回执中的临时状态，不额外产生同名状态事件。

客户端固定向官方平台请求 `GET /api/v1/client/game-portals/{app}/player?portal_revision=...` 和 `POST /api/v1/client/game-portals/{app}/identity`。这些请求携原 UAS AppKey 与用户 JWT，拒绝重定向。供应商网页地址不能替换官方平台地址。身份码由供应商后台按开放平台文档兑换。

## 下载和入服

网页只能选择本游戏的 `serverId`。客户端重新读取审核状态、区服归属、可用性、端点及内容版本，在准备和真实连接前再次核验。网页传入 IP、端口、扩展包地址等额外参数会被拒绝。

网游配置了专用扩展同步服务器时，客户端在打开网页前展示扩展包版本和大小并请求同意。确认后打开网页，顶部显示下载、校验、安装及引擎重载进度。同步期间点击入房会收到终态 `failed`，原因是 `expansion_sync_in_progress`，待同步完成后由用户重新点击加入。同步失败时网页保留，原生顶栏提供重试。扩展版本更新需要重新确认。

未配置同步服务器的网游在加入区服时准备必需扩展包。可选外观首次下载需要原生许可，玩家也可以使用默认外观继续。

网页和临时 Cookie 会话在准备、入服失败或取消时保留。用户关闭页面、切换账号或重载主文档会作废旧请求并取消未完成的加入。入服走普通多人的同一个原生同步、真实席位预约、引擎连接及 admission 确认协调器。确认成功后关闭网页进入房间，离开房间或被踢回玩法大厅，并恢复原内容与外观。退出网页后销毁隔离 Cookie 容器，不与论坛或其他游戏共享登录状态。

供应商可在自己的网页和服务端维护匹配队列。匹配完成后仍只能选择已审核且属于本游戏的区服 ID；客户端的取消加入不会代替供应商自己的排队取消接口。

## 独立 Android 联调包

`-PgamePortalUiTestPackage=true :rwpp-android:assembleDebug` 生成正常引擎与 Launcher 的 `io.github.rwjs.portaltest`，桌面显示“RWJS网页入口联调”。仅此 Debug 变体启用本机 18080/18081 测试地址和公开合成 AppKey，用户通过原生登录输入合成账号；无 JWT、密码或 PIN 注入入口。测试包的扩展、地图和外部内容也定向到它自己的私有目录，保留正式安装与用户数据。Release 不包含测试 Provider。
