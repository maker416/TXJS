# 更新日志：扩展与美术包管理优化

日期：2026-11-03

- 重构扩展界面，采用与启动器整体风格一致的卡片、状态提示与操作栏，目前集中展示美术包管理。
- 将美术包管理从设置页移动到扩展页，统一提供导入、刷新、启用、停用、删除和恢复内置外观操作。
- 优化手机横屏布局，固定顶部工具栏和当前外观状态，压缩卡片高度，让常用操作更容易触达，减少反复上下滑动。
- 修复启用材质类美术包后主页回退为旧版布局的问题；材质、配色等主题继续使用新版主页，保留主题自定义菜单的能力。
- 修复停用材质包后，局内已有单位和建造列表仍显示旧贴图的问题。切换时同步刷新资源与图片缓存，无需重启客户端。
- 修复冷启动后的贴图同步遗漏，并增加刷新失败提示和重试入口，避免界面状态与实际贴图不一致。
- 切换贴图时保留可继续的单人地图和单位；房间连接或开局期间阻止切换，避免影响当前会话。

本次 Android 正式包已在 Redmi K30 Pro 验证：冷启动恢复、启用与停用、同一场沙盒继续游戏、已有激光坦克与建造列表图标切换，以及新版主页显示。桌面端已通过编译，尚未做桌面游戏实测。
