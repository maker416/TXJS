# 绿色玩家卡片 · 静态演示

这个独立美术包演示等待战斗室的较大玩家槽位、业务列比例、左侧头像格，以及名字、位置、队伍、延迟下方的静态信息格。通用玩家和房主内容各有四个配置行，第一行含五格，并演示显式宽高、不同弹性权重和空装饰格。外观采用深色底与绿色边框，房主使用金色徽章，AI 示例使用紫色、蓝色和绿色徽章。真人优先显示可用的账号头像；本包未提供默认头像图片，没有可用账号头像时使用客户端内置真人图标，AI 使用内置机器人图标。

需要包含 `[room.player.sizing]` 和扩展信息格功能的客户端；旧客户端可能忽略新增尺寸字段，或只保留三行四格。当前内置外观及旧包也默认显示头像，本包额外启用静态信息行和对应外观；头像样式与默认图片不依赖 `card.enabled`。旧包、旧版房间布局字段的兼容规则见[战斗室美术包开发](../../../docs/战斗室美术包开发.md)。本包只扩展玩家槽位内部，房间面板仍按客户端的 PC、Android 和窗口尺寸规则排列，新增信息格不会产生玩家席位、权限或自定义动作。

## 内容来源

`theme.toml` 中的胜负数、专家称号和 AI 难度文案全部是固定演示内容，不代表实际账号战绩或 AI 配置。名字、位置、队伍、延迟、准备状态、同步进度和名片继续读取真实业务状态。账号头像是独立的动态数据，不受这些写死文案影响。

本机玩家可直接取 `AccountSession` 中已登录账号的头像。远端玩家须经已有房间身份服务确认，服务需支持 `room_id_membership_verified`；客户端不凭游戏昵称猜账号。服务不支持核验、身份未知、未设置头像或头像加载失败时使用主题默认头像，再回落内置图标。因此不能保证房间里所有登录玩家都显示账号头像。

- 通用玩家显示“联机玩家”“战绩：128胜 / 23负”等固定文案，四个配置行展示宽高和换行。
- 房主显示金色“房主”徽章和同样的四行排版演示；AI 默认显示“进攻专家”。角色选择来自客户端真实状态，文案不会赋予权限。
- 出生位置 2、3、4 分别显示“防守大师”“进攻专家”“经济发展”。这是位置覆盖，真人进入相同位置也会看到同样的静态文案。
- 观战玩家显示“观战席”和“静态信息展示”。

指定出生位置优先于本机、房主、AI 和观战内容，命中后整份替换通用内容；此示例没有本机专用覆盖，以便本机房主仍显示房主内容。需要动态数据时应在客户端增加正式数据来源，目前不支持网络接口、变量占位或脚本。

## 导入与修改

将本目录的 `theme.toml` 放在 ZIP 根目录，后缀改为 `.rwtheme`。从“主界面 → 资源中心 → 扩展（美术包管理）”导入并启用。交付包输出位置为仓库根目录下 `build/artifacts/room-player-cards/room-player-cards.rwtheme`。

`[room.player.sizing]` 中本包设置 `minHeight = 240`、`widthPercent = 96`，让玩家槽位至少 240dp 高、占玩家表可用宽度的 96%；内容较多时仍可继续撑高。`nameWidth = 0.48`、`spawnWidth = 0.16`、`teamWidth = 0.16`、`pingWidth = 0.2` 是业务列相对权重，不要求总和为 1。可用范围为：最小高度 0（原生）或 48–480dp，宽度 50–100%，各列权重 0.05–10 的正有限数。旧 `room.player.rowHeight` 和直接位于 `room.player` 下的同名列宽字段仍然忽略，不要把新字段移到旧路径。

编辑 `[[room.player.card.<内容>.rows]]` 的 `cells` 可以增加信息格；一个 `rows` 表是一个配置行，每份内容最多 12 行、每行最多 12 格，总计最多 144 格。`card.columns` 默认 4，范围 1–12，表示每条视觉行最多的格数，格子也会根据可用宽度提前换行。本包第一配置行有 5 格，`columns = 4` 时至少显示为两条视觉行；第 4 个配置行仍会显示。`rowSpacing` / `cellSpacing` 默认 6dp，可在 0–24dp 内控制视觉行间距及格间距，本包分别设置为 8 和 6。

行的 `height` 和格子的 `height` 都是最小高度：0 自动，其他值范围为 24–240dp，内容较高时继续撑高，不用于裁内容。格子的 `width = 0` 使用弹性宽度，按 `weight` 分配当前视觉行空间；`weight` 默认 1，范围 0.1–10，仅对弹性格生效。本包使用 2.5 和 1.0 对照。非零 `width` 范围为 24–1200dp，本包展示 40、88、96、112 和 260dp；宽度超过可用空间时缩小。无文字、无图标但设置背景色、边框颜色或非零尺寸的格子可以保留为装饰；本包第一配置行的最后一格即为空装饰格。

使用 `card.content` 配置通用内容，`card.local`、`host`、`ai`、`spectator` 配置真实角色的覆盖，`card.slots."1"` 等配置出生位置。默认头像可通过相应内容的 `avatarImage` 指定包内相对路径；这些字段仅在没有可用账号头像时生效，不能覆盖真实账号头像，缺失或损坏时回落内置图标。AI 使用主题默认头像或内置机器人图标。

将 `[room.player.card.avatar]` 的 `enabled` 改为 false 可隐藏头像格并保留已开启的信息行；将 `[room.player.card]` 的 `enabled` 改为 false 只关闭静态信息行，头像和默认头像配置仍生效。停用主题后恢复内置头像格及账号头像规则。

`avatar.size = 48` 表示头像随稳定内容高度增大时的上限，不是固定尺寸。配置范围为 32–64dp，紧凑视图另有 56dp 上限，桌面视图为 64dp。普通字体下，无信息行的内置紧凑槽位约 52dp 高（含外边距）、头像约 40dp；桌面槽位约 64dp 高、头像约 48dp，文字放大可撑高玩家行。本包的静态信息行可以促使头像增长至 48dp 上限。全表头像列宽统一，临时准备/同步状态不改变头像尺寸和列宽。头像按槽位最小高度、配置行/格最小高度与列数估算稳定尺寸；固定宽度在窄屏造成的额外换行只增高玩家行，不重新拉大头像。

修改已安装的包时，先退出房间，停用并等待刷新完成，删除旧包后再导入。替换下载目录里的 `.rwtheme` 文件不会更新已安装副本。

## 验证

检查长昵称、满员滚动、狭窄窗口、准备/同步进度、名片点击，以及切换或停用主题后的恢复。确认大槽位和列比例生效、五格自动换行、第 4 个配置行保留、空装饰格可见、弹性权重不同、窄屏显式宽度缩小，最小高度不会裁掉内容。还应验证两个 `enabled` 开关独立、头像自适应与上限、全表头像列对齐、本机账号头像、远端已核验头像和各类默认头像回落；停用后内置头像仍应存在。绿色卡片中的额外文案是静态展示，账号头像按实际身份动态加载；本包不提供房间整体重排。桌面 Compose 测试截图不能代替 Android 真机与联网测试。
